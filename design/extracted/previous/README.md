# Previous icon artwork

The five pictograms as they were *before* being redrawn from the mockup
(2026-09-08). Exported from the then-current VectorDrawables, so they are a
faithful record of the old artwork.

They are kept because the project has no git history yet, so overwriting
`app/src/main/res/drawable/ic_*.xml` was otherwise irreversible.

To put one back, convert it and overwrite the drawable — or restore the XML
itself from OneDrive version history (right-click the file in Explorer →
*Version history*), which holds the exact original.
